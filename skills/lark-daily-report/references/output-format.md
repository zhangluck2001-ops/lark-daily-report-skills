# 日报输出格式

## 今日工作总结

- 写 3-5 条，最多 6 条。
- 每条一行，使用 `1. 2. 3.` 编号。
- 每条只写一件事：`动作 + 结果/进展 + 必要价值`。
- 单条不超过 80 个中文字符；整体不超过 500 个中文字符。
- 同一事项只写一次，禁止把“改造、验证、安装、同步”拆成多条重复描述；能合并就合并。
- 优先写重点工作和可交付成果，不写素材来源、清洗过程、聊天过程。

## 明日工作计划

- 写入前必须问用户：明天有哪些计划、候选计划里哪些不是自己的工作需要删除、还有什么补充事项。
- 用户回复前不要自动填写明日计划。
- 写 3-4 条，最多 5 条。
- 每条一行，使用 `1. 2. 3.` 编号。
- 每条只写一个明确行动：`要做什么 + 目标/交付物`。
- 单条不超过 70 个中文字符；整体不超过 350 个中文字符。
- 不写泛泛表态，如“继续优化”“持续跟进”，除非说明具体对象和产出。

## 去重规则

- 先把素材归并成“事项”，再写日报；一个事项只占一条。
- 如果两条都围绕同一交付物，合并成一条。
- 如果只有会议学习，没有个人产出，写成“参与/学习并提炼要点”，不要扩写成多条成果。
